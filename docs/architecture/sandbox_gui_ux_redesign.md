# UX 改版方案 · Sandbox GUI

本文给出以开发者为主要用户的 sandbox-gui UI/UX 改版方案，用于指导后续交互设计、界面实现与增量迭代。目标是提升调试效率、风险感知能力与可维护性，同时为后续功能拓展留出清晰的布局与交互模式。

## 1. 用户与目标
- **目标用户**：引擎/玩法开发者，日常需要观察模拟状态、快速定位问题、调整参数并回放结果。
- **核心目标**：
  - 在大型场景下快速理解世界状态与资源分布。
  - 以最少的操作完成播放控制、断点调试与数据导出。
  - 监控性能与异常状态，及时发现潜在风险。
  - 逐步扩展到 WorldGen、回放、性能分析等高级功能。

## 2. 现状痛点（原型反馈）
- 布局松散、导航缺失；常用功能散落在不同窗口，需要频繁切换。
- 状态反馈不一致：播放状态、版本号、错误提示分布在多处，难以第一时间定位。
- 面板数量多但信息层级模糊，缺少“重要信息优先”策略。
- 视觉风格非统一，缺乏“安全沙箱”主题感与风险识别手段。

## 3. 设计原则
- **安全透明**：显著展示沙箱权限、运行状态、资源风险。
- **效率优先**：平均三次以内操作完成核心任务（播放控制、实体定位、日志导出）。
- **渐进复杂度**：初学者可以快速上手，进阶用户能开启更多面板与自定义布局。
- **一致性**：统一组件、配色与反馈模式，降低认知负担。
- **可扩展性**：导航与面板支持按模块扩展，保留未来接入测试、性能分析的空间。

## 4. 信息架构
- **左侧导航（Dock/Sidebar）**：按功能域分组
  1. *Monitor*：总览、世界地图、性能监控。
  2. *Control*：播放控制、事件时间轴、命令中心。
  3. *Inspect*：实体列表、Inspector、日志/事件。
  4. *WorldGen*：世界生成参数、批量操作、校验。
  5. *Tools*（预留）：脚本、自动化测试、插件。
- **顶部状态条（Status Bar）**：
  - 沙箱状态（Running / Paused / Stepping）、速度倍率、世界版本、权限模式。
  - 资源占用（FPS、Runtime Step、内存）+ 快速告警提示。
- **主内容区**：采用 DockSpace 布局，默认布局提供三视图（地图、场景、Inspector），可记忆用户调整。
- **底部操作栏**：播放控制与事件日志（Condensed），便于单键操作与历史回看。

## 5. 默认布局（Desktop-only）
```
┌───────────────┬───────────────────────────┬──────────┐
│ Top Status Bar│                           │          │
├───────────────┼───────────────┬───────────┤ Inspector│
│ Left Nav      │ MapView       │ SceneView │ Panel    │
│               │ (可拆分 Tab)  │           │          │
├───────────────┴───────┬───────┴───────────┴──────────┤
│ Bottom Control & Timeline / Console                      │
└──────────────────────────────────────────────────────────┘
```
- MapView 与 SceneView 支持 Tab/分屏切换，保留键鼠交互提示。
- Inspector 根据选中上下文自动切换实体/资源/世界信息。
- 底部时间轴承载关键信息：事件标记、快照、录制进度。

## 6. 核心任务流程
1. **启动与快照加载**：欢迎页提供最近世界/配置列表、快速启动按钮、最近告警摘要。
2. **世界运行**：
   - 状态条一目了然显示运行状态 + 快捷键提示。
   - 左侧导航 `Monitor > Overview` 提供地图缩略图 + 指标卡片。
3. **实体定位/排查**：
   - `Inspect > Entity Explorer`：支持筛选/排序、双击跳转 MapView 高亮。
   - Inspector 面板整合属性、需求曲线、行为队列；提供“固定视角”与“对比”模式。
4. **性能/风险监控**：
   - `Monitor > Performance`：ImPlot 图表展示帧耗、Runtime Step、内存。
   - 告警中心列出资源耗尽、异常命令、崩溃回放入口。
5. **世界构建/热更**：
   - `WorldGen` 面板以卡片式参数分组（基础参数、噪声、生成规则），提交后展示验证结果与差异对比。

## 7. 视觉语言
- **配色**：主色 `#1F3B52`（深蓝）、辅色 `#2E6F95` / `#53A7D8`；风险提示用 `#E17F60`（警告）、`#D74343`（危险），成功用 `#4FB477`。
- **排版**：标题/导航使用半粗标题（16–18px），正文 13–14px，保持信息密度。
- **组件风格**：ImGui 自定义主题 + 统一圆角（4px），暗色低亮背景 + 高对比文字。
- **图标与标签**：引入风险、运行、暂停等常用图标（FontAwesome/内置）。

## 8. 交互与反馈
- 状态改变（播放、暂停、热更）采用顶部 Toast + 底部时间轴标记双重反馈。
- 异常（Runtime 错误、资源不足）触发状态条彩色条 + 告警面板自动展开。
- MapView 操作提供浮动提示（缩放比例、筛选已启用项），支持 Ctrl+F 快速定位实体。
- 命令中心支持批量操作（队列可视化）与撤销（若运行时支持）。

## 9. 渐进式引导
- 首次启动展示三步引导（认识布局、快捷键、告警中心）。
- 提供 `?` 帮助入口，链接到 `docs/guides/sandbox_gui_smoke.md` 与新的 UI 指南。
- 底部控制栏在首次使用时展示快捷键提示，可在设置中关闭。

## 10. 后续扩展预留
- **布局管理**：保存/加载自定义布局，团队共享模板。
- **多会话支持**：顶部状态条允许切换运行时实例或远程沙箱。
- **插件化**：Left Nav `Tools` 板块支持脚本、AI 助手、自动化测试插件。

## 11. 实施路线建议
1. **Phase A · 结构重塑**
   - 实现左侧导航 + 顶部状态条的基础布局。
   - 重构 DockSpace 默认布局，集成 MapView/SceneView/Inspector/控制栏。
   - 引入统一主题与组件样式。
2. **Phase B · 任务流优化**
   - 实现实体浏览器、告警中心、性能监控面板。
   - 打通状态栏告警与面板联动，完善交互反馈。
3. **Phase C · 高级功能**
   - 完成 WorldGen 面板与热更流程优化。
   - 引入时间轴/快照管理、录制/导出。
   - 规划插件与多会话支持的扩展接口。
