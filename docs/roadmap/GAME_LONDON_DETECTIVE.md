# 路线图 · 侦探游戏（伦敦·世纪末）

愿景对齐：见 `docs/game-design/vision.md`。

里程碑（Milestones）
- M0 基调样片（1 周）
  - 雾夜小巷可行走；证据卡/证据板/对话框占位。
  - 验收：拾取并放置 3 张占位证据。
- M1 证据板与时间线（1–2 周）
  - 证据板节点/连线/标签/高亮；时间线拖拽与冲突提示。
  - 验收：12 张证据、3 个假说模板、一次时间线还原。
- M2 对话与对质（1 周）
  - 话题池 + 证据插入；对质成功/失败影响分支。
  - 验收：达成 2 个结局分支其一。
- M3 视听打磨（1–2 周）
  - 雾效、光影、环境音、主题动机；
  - 验收：10–15 分钟可演示切片。

依赖与对接：
- UI 2D 画布/节点交互（引擎 GUI）
- JSON 资源加载与存档（Runtime API）
- 场景与光照/雾参数（渲染管线）
- 音频回放（基础混音）

风险与决策点：
- 若证据板交互成本高 → 采用列表+关系表的折中 UI；
- 若对话系统开发超期 → 以“对质问答”最小实现替代自由话题。
