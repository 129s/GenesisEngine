# 叙事结构与世界观（Narrative）

时间与地点：
- 1899 年深冬至 1900 年初，伦敦跨年；雾、雨、潮湿、煤气灯、钟声、蒸汽与船笛。

主角设定（建议）：
- 名字：Arthur Wren（可改）。前军医转私家侦探，轻度失眠与耳鸣。
- 动机：一次未解失踪案留下阴影；对“理性之边界”着迷。

重要角色原型：
- 线人（码头与酒馆网络）；
- 报社记者（渴望独家，可能操纵舆论）；
- 学院学者（自然哲学/东方学/民俗学，兼具求真与傲慢）；
- 私人会馆管事（人脉广，守口如瓶）；
- 警探督察（务实、功利，与主角既合作又牵制）。

派系与张力：
- 秘学社团 vs 科学会：争夺叙事权；
- 旧贫民窟改造派 vs 保守势力：涉及拆迁、纵火与投机；
- 报业竞争：信息战与造谣。

章节结构（三幕五章·建议）：
1. 雾中来信：接到一封匿名信，指向南岸码头的失踪案（教程+证据板引入）。
2. 织影巷：在贫民区搜集证据，遭遇假线索与恐吓（对质与矛盾引入）。
3. 会馆之夜：潜入私人会馆，获取档案碎片（时间线拼接）。
4. 雾灯下的钟鸣：真凶未现，暴露更大阴谋（抉择前的情感代价）。
5. 跨年：在钟声与烟火中给出结论，选择“维稳真相/揭露深层”（多结局）。

分支与结局基调：
- 忧郁现实：真相揭露，牵连无辜，主角与相关人付出代价；
- 暗流保全：隐去部分真相，保护弱者，社会表面平静但隐患不去；
- 模糊未知：保留“超常”解释可能，主角理智受挫但获得新的追索方向。

叙事技巧：
- 以物述事（账册、车票、报纸剪报、手术器械、香灰、书页）；
- 不可靠口述（记忆偏差与自我合理化）；
- 反身观察（玩家的选择被 NPC 记录与评论）。
