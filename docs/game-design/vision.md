# 愿景与基调（Vision & Tone）

- 电梯陈述：
  在 1899 年的伦敦雾中，一位心事重重的私家侦探在理性与迷信、真相与安宁之间游走。街灯映着潮湿石板，古老会馆与码头酒馆暗流涌动。你将以推理与直觉，拼合破碎的证据，决定某些秘密是否该被揭开。

- 核心体验目标：
  - 神秘：信息永远不全，线索以错位的片段出现，逼迫玩家建立假说并自证。
  - 忧郁：角色动机与城市氛围充满失落感，代价感贯穿选择与结局。
  - 诡异：现实细节可信，但边缘处隐约超常，保持“可解释的未知”。

- 创作支柱（Pillars）：
  1) 证据与语境：线索有来源、时间与上下文，脱离语境将误导推论。
  2) 可靠的世界：街区、职业、报刊、社交网络遵循历史逻辑。
  3) 破碎的叙事：以“物件/口供/观察”三类片段重组真相。
  4) 情感代价：破案会改变人物命运，真相未必带来善后。

- 题材与风格：
  - 地点：伦敦（怀特查佩尔、南岸码头、苏活、议会广场、泰晤士河沿线）。
  - 时间：1899 年冬至 1900 年初，跨年象征旧世代与新世纪交替。
  - 参考气质：维多利亚末期市井与学院并置、工业与秘学并存。

- 受众：
  喜爱叙事推理、低刺激动作、重氛围与慢节奏探索的玩家。

- 不做/降级：
  - 不做高强度战斗；身体对抗以短促 QTE/逃脱替代。
  - 不做海量程序化案件；主线手工打造，少量支线半开放。
