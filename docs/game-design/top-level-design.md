# 顶层设计与优先级（社会模拟 × 侦探）

本文定义侦探即玩家角色，而系统本体是一套“尽量自然而富有戏剧性”的社会模拟。强调正交系统与原子级交互，案件由世界自演化，系统仅调度显露率，不改事实。

## 北极星愿景（North Star）
- 城市是主角：地点/路径/制度塑造故事；重要行为必须“亲临其境”落地于具体交互点。
- 知识有源头：所见所闻/纸面/流程才形成“已知”；真相层与知识层可并行且矛盾。
- 无指路灯：不高亮目的地；通过信息→候选地点→实地确认的链条推进。
- 后果真实：误判/报道偏差/机构阈值共同决定现实后果，世界继续演化而非软重置。

## 设计铁律（约束）
- 物理化流程：报案/递交证物/检索档案等必须在地点/时段/柜台完成（不允许远程菜单）。
- 原子交互：以“说/交/拿/藏/递/申请”等为原子，系统组合而非脚本剧情。
- 观察分层：逐句/主题/未捕捉三档记录，受距离/朝向/遮挡/人群影响。
- 软导演：仅调“发生率/显露率/可见窗口”，不改已发生事实。

## 核心场景模板（Locations）
- P0：码头/仓库、酒吧/客栈、警局（前台/档案/留置）、出版社/印刷所、寄宿屋/出租公寓。
- P1：法院/验尸所、报社编辑部/零售点、当铺/银行、教堂/会馆、工坊/小型工厂。
- P2：火车站/渡口/枢纽、富人宅邸/看守宅、学院区/研究所、地窖/屋顶/下水道。
参数（各场景均具）：拥挤度×时段曲线、可见度与遮挡、门禁/权限、风险/非法度、证据存留与衰减、谣言增益。

## 核心职业（Occupations）
- P0：巡警/督察、记者/编辑、酒保、码头工、掮客/线人、窃贼。
- P1：法官/验尸官/书记员、医生/药剂师、会馆管事/学者、店主/掌柜、车夫/搬运、看守/门卫。
- P2：律师/辩护人、银行/当铺职员、教士/神职、帮派角色细分、工厂领班等。
职业参数：动机权重（贪婪/义务/名望/恐惧）、风险容忍、社会资本（关系/庇护/债务）、专业能力（伪造/破坏/审计/勘验）。

## 核心系统（按优先级）
- P0 时间与日程（Scheduler）：昼夜/班次驱动人流与窗口开闭；值班/排队形成节奏。
- P0 事件总线（Event Bus）：一切行动产出结构化事件，作为“真相流”。
- P0 感知与日志（Perception/Logging）：基于可见性生成逐句/主题条目，记录来源/时间/可信度/可复核。
- P0 痕迹与证据（Evidence Tracker）：行动落地物证/证言/记录，具可见性/衰减/伪造属性。
- P0 社会关系图（Social Graph · 简）：信任/权力/债务三维，影响情报流与庇护。
- P0 名誉与立场（Reputation/Faction）：影响合作、价码与报道倾向。
- P0 机构行为（Institutions · 简）：警局“受案→巡逻/勘验→简化裁决”的最小闭环（必须在场办理）。
- P0 调度旋钮（Director）：显露窗口/节流/误导率与证据暴露率档位；不改事实。
- P0 调查交互（Investigation UI · 最小）：证据板=知识图谱（仅一致性提示），时间线=可重建性校验；无“指路光”。
- P0 场景/连通（Scene/Portal Graph）：彩色矩形+Portal 箭头表达，纯色 UI；无需 Tilemap。
- P1 经济与筹码（Economy）：现金/人情/情报/债务为通用筹码；供需脉冲影响动机。
- P1 媒体与舆论（Press/Rumor）：立场偏差的报道生成与放大，反向影响机构阈值与公众情绪。
- P1 身份与误认（Identity/Disguise）：伪装/口音/证件与误认概率。
- P2 法理与程序（Law）：搜查令/证据排除/申诉等完整规则。
- P2 交通与载具（Mobility）：马车/渡口/地铁等等待型加速点。

## 交互原子（Actions）
- 话语：Ask/Answer/Claim/Refute/Accuse/Withhold/Gossip（证据可插入）。
- 交易/影响：Hire/Bribe/Threaten/Endorse（引荐与担保）。
- 物理：Open/Lock/Hide/Stash/Take/Place/Inspect（门禁/柜台/档案）。
- 机构：Report/Submit/Request/Queue/Sign（均需在相应柜台/窗口执行）。
注：首版优先实现 P0 所需子集（问答/指控/雇佣/贿赂/开关/藏匿/报案/提交证物/排队）。

## 节奏与导演（Knobs）
- 显露窗口：公共露面/跟进报道；
- 节流：每日显著事件上限；
- 难度：误导率/证据暴露率/机构阈值/处理速率。

## 数据与契约（仅命名，不细化）
- Event、Incident、EvidenceFact、CaseFile、KnowledgeEntry、ReputationRecord、InstitutionTicket、QueueState。

## 开放问题（下一阶段细化）
- 非法证据的接受度边界；
- 误判后的长链后果与修复通道；
- 记者/小报的采样门槛与更正机制；
- 排队与插队的社会规则与担保链；
- 敏感题材表现边界与审美约束。
