# 核心调查循环（Core Loop · 涌现导向）

目标：把“世界自演化→观察记录→知识建模→实地验证→提交论证→现实后果”打磨为清晰且可实现的循环，避免脚本化谜题与指路灯。

1) 世界自演化（Emerge）
- NPC 由需求/人格/日程与规范驱动，产生日常与越轨行为；
- 关键流程（报案/提交/检索）需在具体柜台/窗口/时段完成。

2) 观察与记录（Observe & Log）
- 玩家在可见性允许下获得逐句/主题两档日志条目，记录来源/时间/地点/可信度；
- 环境可检视对象（划痕、票据等）/告示栏/账册均产生日志或证据。

3) 知识建模（Model）
- 证据板作为“知识图谱”：证据/人物/地点与关系（因果/矛盾/同现），仅给出一致性提示，不直接判对错；
- 时间线拖拽重建事件顺序，系统提示冲突但不代判。

4) 实地验证与对质（Verify）
- 通过重返现场、走访人物、查阅档案柜台来验证；
- 对话中可插入证据进行指控/反驳，影响关系与可获取信息的层级。

5) 提交与后果（Submit & Consequence）
- 在警局等机构柜台提交“论证包”（时间线一致性+动机闭环+关键物证阈值），
- 机构按自身阈值/偏见裁定；误判会改变人物命运与玩家名誉，世界继续演化。

最小可行版本（MVP）：
- 固定小地图 + ≥1 起自然发生的盗窃/破坏事件；
- 警局柜台物理化受案/提交/查询；
- 证据板与时间线最小实现（平面节点+直线/冲突提示）；
- 无地图高亮，信息→候选地点→实地确认。

可拓展方向：
- 证据语义关系增强与检验工具；
- 理智/疲劳的轻量表现；
- 夜雾/天气/时段影响可见性与 NPC 行为；
- 多地点链式调查与跨日推进。
