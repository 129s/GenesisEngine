# 坐标与单位映射（WU → RU）

- World Unit（WU）：运行层整格坐标单位（`coord_global/coord_local`）。
- Render Unit（RU）：渲染层每 1 WU 对应的像素尺寸（建议 8 px）。
- 映射关系：`pixel = origin + (WU * RU) * zoom + pan`。
- 缩放：仅允许整数缩放（×2/×3/×4）；关闭抗锯齿，保证像素对齐。
- 虚拟分辨率（建议其一）：
  - 320×180（16:9，信息密度高，×2/×3/×4 友好）
  - 384×216（16:9，更宽裕，亦可整数缩放）
- Scene 外观尺寸：
  - 若缺省尺寸数据，取子节点 WU 包围盒并外扩 1–2 WU margin 作为 Scene 面板矩形。
  - 叶 Scene 无子节点时以 1×1 WU 显示占位（仍可带标题）。
- 坐标对齐：所有顶点、文本起点、箭头基点均落在整数像素；不做亚像素移动。
