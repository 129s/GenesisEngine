# 美术与音频方向（Art & Audio）

美术关键词：煤气灯、夜雾、潮湿石板、斑驳砖墙、旧报纸、磨损皮革、黄铜仪器、暗木家具、雾灯光晕。

色彩：
- 主色：冷灰蓝（雾/夜）、赭褐（木/皮革）、黄暖（煤气灯）。
- 点缀：警笛红、墨绿色（会馆壁纸）、氧化铜绿。

造型与构图：
- 狭长街巷与近景物件压迫感；
- 透视线引导到雾灯与人物；
- UI 采用报刊与档案册视觉母题（页签、金属夹、手写注记）。

角色与服饰：
- 功能性为先：大衣、呢帽、皮手套；
- 通过磨损与补丁体现阶层与经历。

音频设计：
- 环境：雨滴、马车、远处船笛、钟声、煤气灯微弱噪音；
- 拾取/翻页/夹子/笔记的清脆 Foley；
- 远处合唱或风琴片段，营造宗教/秘学对照。

音乐：
- 室内乐编制（大提琴/中提琴/单簧管/钢琴），主题动机低回；
- 重要推理/对质使用动机变奏；结局以和声堆叠表达代价感。
