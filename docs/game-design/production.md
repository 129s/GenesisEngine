# 生产计划与依赖（Production）

垂直切片（Vertical Slice · 4–6 周建议）
- 范围：一处案发地（南岸仓库）+ 3 人物 + 12 证据 + 1 次对质 + 2 个结局。
- 目标：跑通核心循环（观察→证据→假说→对质→结论），验证基调与可玩性。

里程碑与验收：
1) M0 基调样片（第 1 周）
   - 一条雾夜小巷 + UI 占位（证据卡/证据板空壳/对话框）。
   - 验收：可自由走动、拾取 3 张占位证据并放上证据板。
2) M1 证据板与时间线（第 2–3 周）
   - 节点/连线/标签/高亮，时间线拖拽排序与矛盾提示。
   - 验收：完成 12 张证据、3 个假说模板、一次时间线还原。
3) M2 对话与对质（第 4 周）
   - 话题池 + 证据插入；对质失败/成功的分支处理。
   - 验收：完成一次对质并影响结局分支可达。
4) M3 视听打磨（第 5–6 周）
   - 雾效/光影/环境音/动机主题；
   - 验收：“可演示”的 10–15 分钟切片。

引擎依赖（最小）：
- UI 系统：2D 画布、可交互节点/连线、对话框可插入小组件；
- 资源加载：JSON 数据驱动证据/人物/事件；
- 存档：保存证据板状态、时间线、对话进度；
- 场景：基础光照与雾参数、简单碰撞与交互触发；
- 音频：环境循环、一次性音效、基础混音。

风险与缓解：
- UI 复杂度：先实现平面 2D 证据板，图形美化延后；
- 内容创作瓶颈：采用“模板化证据”快速填充，再做个性打磨；
- 性能风险：证据板节点 > 30 时采用分页/筛选。
