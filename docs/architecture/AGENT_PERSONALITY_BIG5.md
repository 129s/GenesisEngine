# Agent Personality · Big Five (OCEAN)

## 概述
- 目的：提供通用、可拓展的人格建模，适配多种需求与行为，不局限于“寻找食物”。
- 模型：大五人格（OCEAN）取值 0.0~1.0，组件 `AgentPersonalityBig5 { O, C, E, A, N }`。
- 使用：在 Planner/Selector 中按需将 OCEAN 投影为行为权重与阈值，形成统一的效用评分（Utility）。

## 通用映射（建议）
- 探索/新奇（O）
  - 距离权重↓（更能接受远处目标）、探索抖动↑、偏好尝试新地点/新资源。
- 自律/计划（C）
  - 距离权重↑（效率/近处）、准备阈值↑（更早补给）、任务序列更稳定（抖动↓）。
- 社交倾向（E）
  - 拥挤惩罚↓（更能接受人群）、社交行为优先级↑、在社交点停留时间↑。
- 亲和/合作（A）
  - 合作/让度/交易倾向↑（后续用于群体交互）、冲突阈值↑。
- 焦虑/风险（N）
  - 风险/拥挤惩罚↑、库存偏好↑（囤货）、准备阈值↑、偏好安全/高保障路线。

示例（觅食选址）
- `score = w_dist * travelCost + w_occ * occupancyPenalty + w_stock * stockPenalty + jitter`
- `w_dist = 1.4 + 0.8*C - 0.8*O`
- `w_occ  = 0.4 + 1.6*N - 1.0*E`
- `w_stock= 0.4 + 1.0*N + 0.6*C - 0.4*O`
- `prepareMargin = base + 6*C + 6*N`
- `jitter ~ U(-σ,σ), σ = 0.2*O - 0.1*C`
- 无人格组件则回退为引擎默认行为。

## 三个示例画像（用于 Demo）
- 探索家（Explorer）
  - O=0.8 C=0.4 E=0.6 A=0.5 N=0.3
  - 行为：更愿意尝试远处资源，轻微探索抖动，适度社交。
- 稳妥派（Planner）
  - O=0.3 C=0.8 E=0.4 A=0.6 N=0.5
  - 行为：效率优先/提前准备，偏好近处/高保障点，谨慎避拥挤。
- 社交控（Socializer）
  - O=0.5 C=0.5 E=0.9 A=0.6 N=0.2
  - 行为：偏好社交点/拥挤环境，移动积极、探索适中。

## 实现要点
- 组件：`AgentPersonalityBig5`（Registry 上挂载）。
- 翻译层：在具体 Planner/Selector 中将 OCEAN → 权重/阈值/抖动。
- 线程边界：人格仅在 Runtime 线程使用；GUI 通过 Telemetry 只读投影字段（如 agent 名称/当前行动），必要时增加可见摘要。
- 向前兼容：缺省时维持现有行为；各 Planner 独立扩展其映射，无需一次性覆盖全部系统。

## 后续拓展
- 将 OCEAN 纳入更多行为域：工作排程、休息/能量管理、社交邀请/响应、探索/旅行、风险/冲突处理。
- 通过存档/配置定义画像模板，支持批量生成 NPC。
- 在 Inspector 中展示 OCEAN，并支持运行时调整（调参实验）。
