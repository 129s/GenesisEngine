# 系统设计（Systems）

证据系统（Evidence Cards）
- 数据：`id, 名称, 类型, 来源地点, 时间戳, 关联人物/地点, 可信度, 标签[]`
- 交互：拾取/检视（旋转放大）、做注记、贴上证据板。
- MVP：固定 12 张；扩展：可生成衍生证据（如化学试剂反应结果）。

证据板与思维导图（Mind Map）
- 节点：证据/假说；边：关系（因果/相斥/转移/伪造/同一来源）。
- 规则：特定模式触发“假说模板”（如“动机+手法+机会”）。
- UI：2D 平面拖拽、节点高亮、快捷筛选标签。

时间线系统（Timeline）
- 数据：`事件{t, 地点, 当事人, 证据引用, 可信区间}`
- 玩法：玩家拖拽事件排序；矛盾点高亮但不代判错对。
- 扩展：多角色叙述时间线对齐/冲突可视化。

对话与对质（Dialogue & Confrontation）
- 结构：话题池 + 态度（友好/戒备/敌对）+ 证据插入；
- 判定：以“语境正确性”与“人物关系”而非数值堆叠；
- 失败后果：封闭分支/降信任/触发伏击或驱离。

理智/疲劳（Sanity/Fatigue · 轻量）
- 效果：观察判定阈值、对话失误容忍度、屏幕噪点与听觉幻响；
- 恢复：休息/音乐/熟食；
- 控制：保持为氛围调味，不做惩罚性数值游戏。

场景与可见度（Fog & Light）
- 天气/时段影响可见度与巡逻路径；
- 光源与湿滑路面作为轻度环境挑战。

档案与报刊（Archive & Press）
- 城市百科：街区、行业、会馆、人物谱系；
- 报刊剪报：引导线索但可能误导。

最小对接清单（与引擎）：
- UI：
  - 证据板 2D 画布（节点/边/标签/高亮）；
  - 对话框（可插入证据卡片）；
  - 档案浏览与全文检索占位。
- 数据：
  - 证据/事件/人物 的 JSON 载入与运行时修改；
  - 简单存档（证据板连接、时间线排序、理智值）。
