# 基础像素图元与抖动/字库规范

- 基础图元
  - 点/线：`putPixel`、`hLine/vLine`（1px）、`line`（Bresenham）。
  - 矩形：`fillRect/strokeRect`（可选 1–2px 圆角，保持像素台阶）。
  - 多边形：`fillPoly/strokePoly`（扫描线填充）。
  - 圆/弧：`circle/arc`（midpoint；小半径，避免灰阶抗锯齿）。
  - 箭头/锚点：三角+矩形组合（5×3/7×5 两档）。
- 填充与质感（零素材）
  - 有序抖动：Bayer 2×2/4×4/8×8；`ditherFill(rect, level, matrix)`。
  - 图案：45° 斜线/十字网点/棋盘（表达未知/禁区/材质暗示）。
  - 渐变（像素风）：线性/径向渐变经抖动量化（气灯/雾晕）。
- 文本与字库
  - 位图字库：6×8 与 8×8 两套字号；等宽优先，保证行高为整数倍（8/16）。
  - 字母即图标：P=Police/警、J=记者、B=酒保、T=贼、C=柜台、A=档案、E=证据（可中/英并列）。
- 颜色与透明
  - 调色板：16/32 色（夜雾冷灰蓝 + 气灯暖黄 + 状态色）；
  - Alpha 离散：0/50%/100%，或以抖动替代半透明。
