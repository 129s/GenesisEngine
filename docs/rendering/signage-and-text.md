# 标识与文本（Signage & Text）

像素字库与字号
- 必备：6×8、8×8；可选：8×12（长文可读性更好）。
- 行高：8 的整数倍；整数像素对齐；禁用矢量抗锯齿。

招牌与铭牌（Sign/Plate）
- 框型：矩形/圆角（r≤2px）；描边 1px；内衬细线；
- 文本：等宽居中；字距固定；超长截断+悬浮展开。

海报与报纸（Poster/Newspaper）
- 纸张材质：见 `materials.md`（Paper）；
- 版式：标题条+正文块+页脚；黑白为主，点阵/斜线影表达灰阶；
- 破损：破角贴纸/折痕贴花（`wear-and-decals.md`）。

符号与图标（Letter-as-Icon）
- 职业/设施：P/警、J/记、B/酒、T/贼、C/台、A/档、E/证；
- 形状：小徽标（圆角 2px 背板 + 字母/单字），便于统一风格。
