# Sandbox GUI · 全面重构设计方案

本文整合最新的 UI/UX 讨论结论，定位开发者日常使用场景下的 Sandbox GUI 重构方向。目标是在统一视觉语言的前提下，提供高效的调试流程、清晰的全局监控与安全的参数调整能力，并为后续扩展（性能分析、插件化、回放等）预留空间。

## 1. 背景与目标
- **目标用户**：引擎与玩法开发者，需要长时间观察模拟、快速定位问题、调参并回放对比。
- **核心诉求**：
  - 以最少操作掌握世界状态、异常与性能趋势。
  - 安全、高效地调整参数或执行危险操作，具备可撤销能力。
  - 提供统一的文件/配置管理、截图录制与导出能力。
  - 维持一致的视觉语言，降低认知负担。

## 2. 设计原则
- **信息优先级明确**：全局状态、告警与任务在第一时间呈现，细节信息可按需深入。
- **效率与安全并重**：调参有撤销/快照保护，危险操作有显著提示。
- **视觉一致性**：统一直角组件、配色、间距与状态反馈。
- **渐进式复杂度**：新手可快速上手，进阶用户可自定义布局、快捷键与主题。
- **扩展友好**：导航、时间轴、通知等系统以可扩展的数据模型实现，支持未来模块接入。

## 3. 全局信息架构与布局
- **顶部控制栏（Control Bar）**：集中主视图导航（Monitor / Scene / World / Settings）与核心模拟控制（Play/Pause、Step、速度倍率），固定在窗口顶部以提升可达性。
- **底部状态栏（Status Bar）**：目前仅展示 Sandbox GUI 版本号，为后续扩展运行状态、告警等信息保留空间。
- **左侧 Browser 面板**：默认分为多种分类：
  - `Scene`：实体、节点、资源等具有层级关系的数据，支持搜索、过滤、树状展开。
  - `World`：世界配置、世界文件、生成历史与可执行操作。
  - `Monitor`：概览卡片快捷入口、指标收藏、告警快速过滤。
  - `Layouts & Themes`：系统自带/自定义布局与主题，支持加载、导入导出。
  - 允许根据主视图区分当前分类，并记忆折叠状态。
- **主视图（Main View）**：依据 Browser 当前分类与状态栏快捷入口激活的模式，在单一画布内呈现 `Scene` / `Settings` / `World` / `Monitor` 等视图；顶部不再保留重复的切换按钮，避免与 Control/Browser 导航重叠。
- **Inspector（主视图右侧）**：展示当前选中对象详情与可编辑字段，提供批量编辑、危险操作保护、撤销快照能力。
- **附加信息层（Overlay）**：Scene 视图内部可选择叠加节点拓扑、标尺、网格等信息；Map View 合并为 Scene 的“节点关系”叠加层，通过按钮/快捷键控制显示。

### 3.5 实施进展（Phase A · Task 1，2025-10-21）
- 已上线顶栏/底栏新布局：状态栏改为顶部展示运行模式与主视图快捷键，控制栏驻留底部集中播放控制、速度倍率与 VSync。
- Browser 面板拆分 Scene / World / Monitor / Layouts & Themes，并驱动 Main View 同步切换；Scene 分类保留树状节点导航（含节点下属的 Agents / Resources 快速入口），聚焦操作与全宽搜索栏由 Browser 负责。
- Main View 引入四象限切换：Scene 子视图包含“世界概览（Map）/ 节点细节（Tilemap）”双模式，World 子视图整合生成/加载/保存操作，Monitor 子视图合并遥测与日志。
- Welcome 面板与命令队列 UI 已完全移除，相关调用点重定向到 Browser 与 World 标签；命令状态通过世界页摘要呈现。
- Inspector 与 Browser 联动：在 Inspector 点击“定位地图/节点视图”时自动激活 Scene Tab 并更新高亮/跟随状态。
- 2025-10-23：Main View 内嵌 Scene/World/Monitor/Settings 标签被移除，导航统一交由状态栏快捷入口与 Browser 分类；Scene Map 空态提示改为画布中心浮层，避免子窗口产生冗余滚动条。

### 3.6 实施进展（Phase A · Task 2，2025-10-21）
- 新增 `DesignTokens` 模块，对颜色、间距、圆角、边框厚度等令牌进行集中管理，并在 AppHost 初始化阶段一次性应用到 ImGui Style。
- Status Bar、Control Bar、Browser、Main View 等主导航组件统一改用设计令牌提供的按钮与 Toast 配色，移除零散的 `PushStyleColor` 魔法数。
- 引入 `SpacingToken` 统一常用间距（XS/SM/MD/LG/XL），Status/Control/Main/Nav 等常用 `SameLine`/`WindowPadding` 均改为令牌值，后续叠加层与数据面板只需引用同一接口即可维护一致节奏。
- 2025-10-22：Sandbox GUI 骨架线框统一为 2px，并通过仅在骨架层绘制边框避免叠加变粗；像素对齐的描边令线条保持 Dock 分割线同样的锐利度，并关闭默认抗锯齿边框；控制栏/状态栏高度统一按整数像素对齐，状态栏描边改由 viewport 前景层绘制从而消除裁剪导致的 1px 缝隙；控制栏/状态栏与主体内容之间取消缝隙，同时为整体界面新增 2px 外框以加强嵌入感。

### 3.7 实施进展（Phase A · Task 3，2025-10-21）
- Scene > Map 视图新增叠加层按钮栏，统一控制节点、资源、实体、轨迹、插值与标尺叠加；配套 Ctrl+1~6 快捷键，按键反馈写入 Toast。
- Scene 画布左上角常驻显示取整后的 UI 帧率，并通过 250ms 节流避免数字频闪。
- Settings 标签补充 VSync 开关，便于在 UI 设置中统一管理渲染同步策略。
- Node 视图改用同款按钮样式管理网格/锚点/资源图层（Ctrl+G/A/R），与设计令牌色板保持一致。
- Browser 选择节点时自动写入聚焦请求：Map 视图平滑居中至目标节点，并在隐藏节点图层时仍高亮选中轮廓，Inspector 高亮同样保持同步。
- 标尺模式支持左键设锚点、右键清除，实时展示 dx/dy 与距离，适配设计令牌的强调色；关闭标尺会自动重置锚点状态。

### 3.8 实施进展（Phase A · Task 4，2025-10-21）
- Browser Scene 分类重建为树状结构：节点层级依据 `parent` 关系自动展开，可记忆折叠状态并支持点击同步 Main View / Scene 聚焦。
- 搜索缓冲支持节点名称与 ID 模糊匹配；命中项自动高亮并强制展开相关分支，便于快速跳转到深层节点。
- Browser 与 Scene 状态联动：点击树节点会同时更新 Scene View 选中态、Map 聚焦与 Inspector 高亮；分类切换时保持主视图与 Browser 的同步。

## 4. 主要板块设计要点
### 4.1 Status Bar
- 显示 `Running / Paused / Stepping` 状态与速度倍率，提供快捷键提示。
- 展示当前世界版本、Schema 版本、权限模式、连接状态。
- 告警图标显示严重级别计数，点击打开 Monitor 中的告警视图。
- Help 菜单包含快捷键速查、文档链接、反馈入口。欢迎页废弃。

### 4.2 Control Bar
- 播放控制：按钮 + 快捷键显示（可自定义），包括倍速、单步、多步。
- 快照：一键保存、加载最近快照，显示当前快照栈状态。
- 日志快速过滤（错误 / 全部）与暂停刷新开关。
- 截图/录制实时快捷键状态提示；点击可停止录制或打开输出目录。
- 任务中心入口图标，显示未完成命令数，点击跳转 Monitor 时间轴。

### 4.3 Monitor 主视图
- **概览卡片**：运行状态、当前聚焦实体摘要、资源/互动节点概况。
- **性能趋势**：UI FPS、Runtime Step 耗时、内存占用、命令队列长度等可选曲线，支持选择时间窗口、暂停刷新、导出数据。
- **资源摘要**：关键资源或互动节点库存、消耗速率的卡片或条形图，可跳转到 Scene/Brower 对应对象。
- **告警中心**：按严重程度排序，支持标记处理、跳转详情。
- **统一时间轴**：整合快照、命令、告警、截图/录制、关键事件。支持过滤（类型/来源/关键字）、时间范围搜索、批量导出。条目可展开查看详情，并链接到日志、Scene 或 Inspector。

### 4.4 Scene / World / Settings 主视图
- **Scene View**：
  - 采用 Tilemap 为主的空间视图；节点拓扑作为叠加层，通过按钮/快捷键显示。
  - Browser 负责选择实体/节点，Scene 负责空间呈现与交互（热点、聚焦、跟随）。
  - 提供叠加层控制（网格、标尺、碰撞、导航网格等）。
  - 节点标签按缩放动态显示；悬停或选中时展示 tooltip。
- **World View**：
  - 展示世界配置分组、生成历史、运行中世界的概览。
  - 提供生成/加载等操作卡片与执行反馈，命令队列面板取消，改为依赖 Monitor 时间轴与 toast。
- **Settings View**：
  - 调整运行配置（速度、调试开关）、Inspector 行为（磁铁/finetune）、默认路径、Help 设置等。
  - 可配置默认布局、主题、快捷键方案。

### 4.5 Browser 面板
- 支持树状展开、关键字搜索、类型过滤、收藏常用条目。
- 每条目可附带功能按钮（定位、跟随、加载、导出等），高风险操作前置确认。
- 记忆 last path，提供原生文件对话框与拖拽加载：拖入世界文件触发加载，拖入配置文件更新路径。
- Layout/Theme 选项卡列出系统模板与用户模板，支持导入、导出、快速切换，状态栏显示当前方案。
- 目录树条目取消垂直间隙，叶子节点统一采用绿色系背景（默认/悬停/选中），让用户一眼区分可展开与终端条目。

### 4.6 Inspector
- 数据模型标注字段来源：公式/只读/可写，UI 只允许编辑可写字段。
- 根据数据类型选择控件：滑条、旋钮、下拉、按钮、tag 列表等；布尔使用切换按钮。
- 默认启用“磁铁”吸附常用值，Alt 暂时关闭吸附精调，Ctrl+单击恢复默认值，右键打开“精确输入”对话框。
- 支持批量编辑（多选实体时显示共用字段），需要显式确认。
- 危险操作使用特殊 skin（警示色 + 感叹号），执行前自动创建带 `danger` tag 的快照；时间轴显示该类快照。
- Inspector 面板顶部提供撤销/重做按钮，对应快捷键 `Ctrl+Z / Ctrl+Y / Ctrl+Alt+Z / Ctrl+Alt+Y`。撤销与快照系统联动。
- 操作反馈通过 toast + Inspector 内部提示同时呈现，失败时展示回滚建议。

### 4.7 Log Console
- 文本按面板宽度自动换行，去除水平滚动。
- 默认隐藏时间戳，可通过“显示细节”切换或 hover 查看原始时间/线程。
- 日志级别颜色：Info（浅灰/白）、Warning（琥珀）、Error（红）；可配合图标或左侧彩条。
- Filter 支持按级别、关键字、多条件组合；允许保存常用过滤器。
- “复制匹配日志”操作结合 Filter 使用，可批量导出当前筛选结果。
- 支持暂停日志流、清空视图；性能保护（保留最近 N 条，超限提示）。
- 导出功能：快速导出当前过滤结果、或导出原始完整日志。

### 4.8 Toast & 通知体系
- 按类型区分展示区域与样式：
  - 严重错误/警报：顶部或状态栏附近，红色主题，点击跳转 Monitor 告警与时间轴。
  - 成功/信息：右下角短时提示，蓝/绿色主题，可跳转相关面板。
  - 提醒/待处理：左下角或控制栏附近，橙色主题，附带操作按钮（撤销、查看详情）。
  - 长任务进度：右上角持久卡片，完成后转换为成功/失败 toast。
- 每条 toast 自动写入时间轴，带上 `source`、`severity` 标签；提供“在日志中查看”按钮应用对应过滤器。
- 支持在 Settings 配置 toast 级别过滤。

## 5. 世界生成与文件交互
- 移除原 World Generation 面板中的路径输入栏与命令队列 UI，路径改为默认配置 + 原生文件对话框与拖拽操作。
- Browser 中的世界/配置条目提供“加载”“保存”“打开所在目录”“复制路径”按钮，自动记忆 last path。
- Settings 中保留默认路径设置与最近路径列表。
- 世界生成成功/失败通过 toast + Monitor 时间轴反馈；可在时间轴中查看命令详情。
- 支持一键导入配置（拖拽文件或通过对话框）。危险操作自动生成快照并标记。

## 6. Snapshot、时间轴与导出
- 时间轴事件统一结构，包含类型、时间戳、上下文、可执行操作。
- 支持记录：快照、命令、告警、截图、录制、用户标记等。类型可扩展。
- 时间轴提供过滤、搜索、时间范围筛选、批量选择与导出功能。
- 在时间轴中选择时间点可导出截图或回放；选择区间可导出录像。条目展示缩略图便于定位。
- 快照支持打 tag（例如 `danger`、`auto`、`manual`），Inspector 撤销产生的快照在时间轴中以对应标签显示。

## 7. 视觉与组件规范
- 统一直角矩形，取消圆角混用；分割线承担主分隔职责，去掉冗余线框。
- 采用设计令牌管理颜色、字号、间距、阴影，组件引用令牌而非硬编码。
- 间距使用 4/8/12 等刻度，保证节奏统一。
- 图标来自统一库（如 FontAwesome），保证风格一致；文字与图标基线对齐。
- 焦点状态明确，支持键盘导航与高对比模式扩展。
- 危险/高风险控件使用特定 skin（警示色、感叹号、边框闪烁）。

## 8. 布局、主题与快捷键管理
- Browser 的 `Layouts & Themes` 标签列出内置/自定义布局与主题，支持预览、加载、导入、导出、删除。
- Settings 允许设定启动默认 layout/theme、快捷键方案。快捷键支持搜索、冲突提示、导入导出。
- 状态栏显示当前布局/主题名称，点击跳转管理页；若由团队配置锁定则提示只读。
- 布局调整支持保存/恢复（含 Dock 布局、面板显隐、叠加层状态）。

## 9. 实施阶段建议
1. **Phase A：布局与视觉统一**
   - 去除 Welcome 面板与命令队列 UI，建立新布局骨架（Status/Control/Browse/Main/Inspector）。
   - 实现统一主题、spacing 与控件样式，梳理设计令牌。
   - 重构 Scene View 将 Map 叠加层整合为可选 overlay。
2. **Phase B：功能整合与体验优化**
   - 完成 Monitor 面板的概览卡、性能趋势、告警中心、时间轴基础功能。

3. **Phase C：高级能力与自定义**
   - 时间轴深化（缩略图、批量导出）、截图/录制离线导出。

   - 完成自动化测试与文档更新（包含交互指南、快捷键列表、最佳实践）。

## 11. 架构重构路线图（2025-10-21 更新）
为配合 UI/UX 重构的持续推进，需同步升级核心代码架构，具体方向如下：

1. **UI 模块化拆分**  
   - 将 Status Bar、Control Bar、Browser、Main View、Inspector 等区域拆分为独立 `View` 类或模块。  
   - `AppHost` 仅承担装配、输入分发与生命周期管理，避免继续膨胀成“上帝对象”。  
   - 规划 `UiContext` / `SandboxSessionState` 等共享状态体，供子视图在不相互耦合的前提下访问。

2. **引入 Presenter / ViewModel 层**  
   - 对 Scene / World / Monitor 各页签构建 Presenter，将 RuntimeBridge 数据解析、过滤、排序等逻辑迁移到纯数据层。  
   - Presenter 输出简单数据模型（可序列化），方便编写单元测试并为未来替换 UI 框架做准备。  
   - 明确刷新节奏与缓存策略（例如遥测节流、命令状态去抖），减轻 ImGui 帧逻辑开销。

3. **统一命令与事件流**  
   - 抽象 `WorldCommandController`，封装生成/加载/保存命令的生命周期、状态轮询与回调。  
   - 为 Toast、日志、快捷键、时间轴写入建立轻量事件总线，使横切能力（提示、审计、自动化）在多个视图间保持一致。  
   - 预留 CLI/自动化入口，确保核心命令逻辑可在无 GUI 环境复用。

4. **布局与主题配置层**  
   - 将 DockBuilder 初始结构、主题令牌、快捷键映射等抽离为 `SandboxLayoutConfig` 与 `UiTheme`。  
   - 支持序列化 / 反序列化，后续 Layout/Theme 管理界面直接操作该配置层，而非散落的全局变量。  
   - 调整文档中布局自定义、主题切换相关流程，以配置层为唯一事实来源。

5. **源码拆分与测试支撑**  
   - 按主视图页签拆分超大文件（现有 `AppHostPanelViews.cpp` 可细分为 SceneView.cpp、MonitorView.cpp 等）。
