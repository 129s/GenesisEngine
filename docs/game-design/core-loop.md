# 核心调查循环（Core Loop）

目标：将“收集—假设—验证—还原—抉择”打磨为清晰且可实现的循环。

1) 勘察现场（Observe）
- 自由移动与近距离交互；环境中存在可观察对象（血迹、脚印、划痕、票据）。
- 工具：手电/火柴、放大镜、随身笔记、一次性化学试剂、简易照相机。

2) 收集与标记（Collect & Tag）
- 获取“证据卡”，每张携带 元数据：来源地点、时间、类型（物证/口供/文献/观察）、可信度。
- 玩家可为证据添加“标签”（人物、地点、动机、手法）。

3) 组装假说（Hypothesize）
- 在“思维导图/证据板”中连接证据 → 生成“假说节点”。
- 系统根据连接的合理性给出“置信区间”，但不直接判定对错。

4) 验证与对质（Validate）
- 通过重返现场、走访人物、查阅档案来验证；
- 对话中可抛出“矛盾点”进行对质，若站不住脚则降低信任或触发反制。

5) 还原与抉择（Conclude）
- 填写案件复盘表：时间线、动机、手法、关键转折；
- 做出抉择：交付警方/掩盖真相/保护当事人/继续深挖。

最小可行版本（MVP）：
- 单一案发地点 + 3 位关键人物 + 12 张证据卡；
- 证据板为 2D 平面节点连接，支持标签与简要注释；
- 一次对质流程 + 一次结论抉择，产出 2 个不同结局分支。

可拓展方向：
- 证据间“语义关系”增强（因果/转移/伪造/目击矛盾）；
- 轻量“理智/疲劳”条影响观察与对话判定；
- 夜雾/天气/时段影响可见度与 NPC 行为；
- 多地点链式调查与跨日推进。
