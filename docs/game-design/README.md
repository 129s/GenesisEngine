# 侦探游戏（伦敦·世纪末）——设计文档索引

本目录收录与侦探游戏相关的产品与玩法设计，面向引擎组并行开发期间的同步协作：

- 目标：在不打断引擎研发节奏的前提下，持续沉淀可实现的游戏设计资产（可用于垂直切片/演示关卡）。
- 范围：愿景与基调、核心循环、叙事结构、系统设计、美术与音频方向、生产计划与依赖清单。

索引：
- vision.md — 游戏愿景与基调、创作支柱、体验目标
- core-loop.md — 核心调查循环与关键交互
- narrative.md — 世界观、人物、章节结构与分支
- systems.md — 线索/时间线/心像/理智等系统设计
- art-audio.md — 美术风格、UI 语言、音频与音乐方向
- production.md — 垂直切片范围、里程碑、引擎依赖与风险
- top-level-design.md — 顶层社会模拟设计与优先级（P0/P1/P2）
- mvp.md — MVP 目标/范围/验收与风险（首版切片）

关联文档：
- ../roadmap/GAME_LONDON_DETECTIVE.md — 路线图与里程碑
- ../status/backlog/game-design.md — 设计侧待办清单
- ../status/game_design_kickoff_2025-10-22.md — 启动状态记录

约定：
- 设计文档以“可实现”为第一原则；每个系统描述都包含最小可行版本（MVP）与扩展思路。
- 与引擎对接时，优先给出数据结构与 UI/交互最低需求，便于并行落地。
