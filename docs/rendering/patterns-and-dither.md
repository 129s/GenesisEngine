# 图案与有序抖动库（Patterns & Dither）

有序抖动（Bayer 矩阵）
- 2×2：`[[0,2],[3,1]]`
- 4×4：`[[0,8,2,10],[12,4,14,6],[3,11,1,9],[15,7,13,5]]`
- 8×8：标准 Bayer8（建议代码内置）
用法：`level∈[0..1]` → 与矩阵阈值比较，决定取前景/背景色；作为渐变/知识雾的离散透明近似。

图案（Pattern）
- Hatch45：45° 斜线（密度可调，1:1 像素节奏）；
- Cross：十字网点；
- Checker：棋盘；
- Dots：规则点阵（可用于金属拉丝高光点）；
规则：所有 pattern 须以 `phaseAnchor=(0,0)` 或对象原点锚定，避免相机移动时漂移。

线影与网点的语义
- 斜线：禁区/警戒/隔离；
- 十字：AO/暗面/污渍增强；
- 棋盘/点阵：材质质感或灯晕核心区域。
