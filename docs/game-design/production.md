# 生产计划与依赖（Production）

垂直切片（Vertical Slice · 4–6 周建议）
- 范围：固定小地图（彩色矩形）+ ≥1 起自然发生的盗窃/破坏事件；
- 目标：跑通“自演化→观察日志→知识图谱→柜台提交→现实后果”的核心循环。

里程碑与验收：
1) M0 事件与日志（第 1 周）
   - 事件总线与可见性；日志视图与基础 UI 占位（证据板空壳/对话框）。
   - 验收：可自由走动；在酒吧/码头看到逐句/主题两档日志条目。
2) M1 越轨与报案（第 2–3 周）
   - 实现盗窃/破坏原子行为；警局前台/档案柜台的 `Report/Submit/Query/Queue`；
   - 验收：至少 1 名 NPC 亲赴前台完成报案；玩家可旁观并在日志中留痕。
3) M2 证据板与时间线（第 4 周）
   - 节点/连线/冲突高亮，时间线拖拽与矛盾提示；
   - 验收：提交一次“论证包”，并被简化裁决接受/驳回并产生后果。
4) M3 媒体与显露（第 5–6 周）
   - 出版社/报道生成；显露窗口/节流旋钮调优；
   - 验收：报道影响警局响应/公众情绪，整体演示 10–15 分钟。

引擎依赖（最小）：
- UI：2D 画布（证据板/时间线）、对话框可插组件、日志/档案浏览；
- 资源加载：JSON/内存结构（Event/Evidence/Case/Knowledge）；
- 存档：证据板状态、时间线、名誉与日志；
- 场景：彩色矩形/Portal、交互触发、队列/排队；
- 音频：环境循环与基础 Foley。

风险与缓解：
- 涌现不足：提高稀缺/机会，启用显露窗口，但不捏造事实；
- UI 复杂度：证据板先做平面直线，样式延后；
- 性能：活跃区高保真，外围统计近似；
- 法理边界：先行“简化裁决”，完整法庭后续引入。
