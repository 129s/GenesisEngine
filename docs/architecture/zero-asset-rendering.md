# 零美术素材渲染评估与指南（Zero-Asset Rendering）

目标与约束
- 无外部贴图/精灵/瓦片集与图标库，全部以程序化形状/线型/渐变/噪声实现；
- 字体策略需拍板：允许嵌入 1 款开源字体（推荐）或采用内置矢量笔画字体/系统字体回退；
- 风格定位：报刊/档案风格（线框与排版）、煤气灯与夜雾以渐变与噪声表达。

优势（Pros）
- 生产效率：免美术管线与资产管理，工程迭代快；
- 一致美学：统一几何/版式语言，风格稳定；
- 体积与兼容：打包体积小、跨平台一致；
- 程序化表达：雾、灯晕、拥挤与队列等以数据驱动渲染，强化“系统感”。

风险（Cons）与对策
- 识别度不足：纯几何易混淆 → 建立严格图例与颜色/线型约定，提供图例面板与图标字母映射；
- 情绪表达弱：无贴图质感 → 使用配色、动效与程序化网点/斜线影增强氛围；
- 文本依赖高：可读性压力大 → 高对比主题、字号动态缩放、文本截断与工具提示；
- 字体版权/嵌入：零素材是否允许字体？→ 建议使用公共领域/开源字体或笔画字体；需拍板。

允许的渲染原语
- 几何：矩形/圆角矩形/线段（实/虚/点）/多边形/圆/弧/贝塞尔/箭头/标尺刻度；
- 图案：程序化网点/斜线影/棋盘/十字与点阵（参数化密度与角度）；
- 渐变：线性/径向（支持混合模式）；
- 文本：等宽或衬线风格；若无法嵌入字体，则采用矢量笔画字体；
- 组合：字母+几何形成“图标”，例如 P=警察、J=记者、B=酒保、T=窃贼、C=柜台、A=档案、E=证据、R=传闻。

主题与可访问性
- 颜色：主色 `#1B263B/#415A77/#E0E1DD`，暖黄 `#E6C07B` 点亮，红 `#9E3B3B`、绿 `#2A6F5C` 为状态色；
- 高对比模式与红绿弱化模式；字号与行高可调。

性能与实现
- 批量绘制：分层 DrawList（base/agents/overlays）+视口裁剪；
- 低开销噪声：基于哈希的 value noise/FBM（片段级函数），避免纹理采样；
- 叠加层开关：Sandbox 默认关闭重计算的热力，按需启用；
- 视觉回归：生成黄金图像用于回归测试（同种子同帧一致）。

落地建议（MVP）
- 第一阶段：仅基础图元/配色/文本与知识雾；
- 第二阶段：加入程序化网点/斜线影与雾动、灯晕；
- 第三阶段：完善图例面板与可访问性切换。

需要拍板的问题
- 字体策略：是否允许嵌入 1 款开源字体（等宽/衬线）？若不允许，采用笔画字体/系统字体回退。
