# 图层/批次/性能与确定性测试

- 图层顺序（背→前）
  - 背景网格/雾 → Scene 矩形 → Portal 箭头 → 柜台/交互点 → NPC/证据 → 叠加 → 文本。
- 批次合并
  - 按层收集 draw calls；合并同色/同笔刷；最近邻整倍数放大。
- 性能预算
  - 目标：绘制部分 < 1ms/帧（视口内数百节点稳定）。
  - 裁剪：视口裁剪 + 远距离 LOD（省略字母/细边）。
- 确定性
  - 噪声以 seed 与 step 为输入；文本布局固定策略，避免跳变。
  - 视觉回归：固定 seed/step 生成黄金图像进行像素或结构化比对。
- 动画节奏
  - 气灯 1–2Hz 闪烁（离散档位）；雾 0.05–0.1Hz 慢移；队列推进 2–3px 瞬移+高亮；过渡 2–3 帧脉冲。
