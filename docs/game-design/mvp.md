# MVP 说明（首版垂直切片）

## 目标
- 验证“世界自演化 × 物理化流程 × 非指路 UI”的核心体验：
  - NPC 由动机与日程自然产生可观察事件；
  - 报案/提交证物等必须在警局柜台完成；
  - 玩家靠观察/报道/档案重建时间线并提交论证包，结案产生真实后果。

## 范围（P0 集合）
- 场景模板：码头/仓库、酒吧、警局（前台/档案/留置）、出版社/印刷所、寄宿屋（彩色矩形表达）。
- 职业：巡警/督察、记者/编辑、酒保、码头工、掮客/线人、窃贼。
- 系统：
  - 时间与日程、事件总线、感知与日志、痕迹与证据（可见性/衰减/伪造占位）、
  - 社会关系图（信任/债务/权力 · 简）、名誉、
  - 机构行为（警局：受案→巡逻/勘验→简化裁决，全部在柜台/窗口进行）、
  - 调度旋钮（显露窗口/节流/难度三档）、
  - 调查 UI（证据板=知识图谱一致性提示、时间线重建校验）。
- 美术与呈现：
  - 地图/房间：彩色矩形 + Portal 箭头；
  - NPC/柜台/证据：字母/小图标；
  - 对话泡：逐句/主题两档文本框（受可见性影响）。

## 玩家能力（最小）
- 移动/观察/记录；
- 问答/指控（可插入证据）；
- 雇佣/贿赂（通用筹码：现金/人情/情报/债务）；
- 在警局前台报案/提交证据/查询档案；
- 在证据板连线与标注，提交“论证包”。

## 关键体验验收
- 涌现性：在固定种子下，≥1 起“盗窃或破坏”类事件自然发生且可被观察到。
- 物理化：至少 1 名 NPC 亲赴警局前台完成报案流程（玩家可旁观并记录不同粒度信息）。
- 非指路：全程不使用高亮目的地；玩家依赖信息链条推理出取证地点。
- 推理与后果：
  - 玩家可提交论证包；若近似正确亦会给出评级；
  - 错误结论会改变人物命运与玩家名誉，并被媒体/警方记录。
- 复现性：相同种子+参数重放得到一致事件与证据统计。

## 难度与参数（首发默认）
- 误导率：中；证据暴露率：中；机构阈值：中；显著事件/昼夜：2–3 起。
- 可见性：逐句记录需近距离+朝向对齐；其余为主题记录。

## 里程碑（建议）
- M0（1 周）事件与日志：事件总线/可见性/日志视图；彩色矩形地图与 NPC 图标。
- M1（1–1.5 周）越轨与报案：盗窃/破坏原子行为；警局前台的受案/提交/查询；
- M2（0.5–1 周）证据板与时间线：一致性提示/重建校验；论证包提交与简化裁决；
- M3（0.5 周）媒体与显露：出版社/报道生成；显露窗口与节流调优。

## 风险与回退策略
- UI 复杂度：证据板先做平面节点+直线，延后样式美化；
- 涌现不足：提高稀缺/机会，增加显露窗口频度，但不捏造事实；
- 性能：活跃区高保真，外围以统计脉冲近似；
- 法理边界：先不做证据排除与完整法庭，仅做“简化裁决”。
